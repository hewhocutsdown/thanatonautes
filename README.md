# Bureau of Incarnations

A small white box with a brass crank. Turn the crank and it prints the brief your soul agreed to before
this life: the Why, the main quest, side quests, KPIs, scheduled obstacles, and the guardian angel assigned
to you.

Inspired by Bernard Werber's *L'Empire des Anges* (*The Empire of the Angels*), where the afterlife is
run something like a company and every life has its goals.

- Drag in circles over the box to turn the crank, or hold the **Hold to wind** button or the space bar.
- Enter a name to get the same brief every time, or link to `?soul=Name`.

Plain static files: Three.js comes from jsDelivr and there is no build step. Served by GitHub Pages from `main`.
